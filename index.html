DNF5 package manager for Termux / Android

dnf5 ported to Termux — RPM packages served from a signed repository

Instalación

Choose the mode that fits your setup. Both install DNF5 from the signed RPM repository hosted on GitHub Pages.

Alternate package manager coexists with apt/pacman

Keeps your existing Termux package manager untouched. DNF runs side by side with apt / pacman.

bash scripts/install-dnf-termux.sh

Follow the step-by-step guide: docs/INSTALLATION.md.

Primary package manager bootstrap

Full bootstrap image with DNF5 as the main manager. Download the release asset, unzip it and install in failsafe mode.

Latest bootstrap release (bootstrap-2026.08.10-r1+dnf5.android-7)

Download bootstrap-aarch64.zip (~73 MB) and install it in Termux failsafe mode.

Repositorio RPM

Signed RPM repository for aarch64, published on GitHub Pages and consumed by DNF with gpgcheck=1.

https://leonisaurov.github.io/dnf-for-termux/rpm/

Repository metadata and packages are GPG-signed; DNF verifies signatures (gpgcheck=1) on every transaction.

Cómo se construye

The project is built and shipped entirely with GitHub Actions workflows:

  • build.yml Build Compiles the DNF5 stack for Termux.
  • deploy.yml Deploy Signs and publishes the RPM repository to /rpm/ on gh-pages.
  • bootstrap.yml Bootstrap Generates the bootstrap image and publishes it as a GitHub release.
